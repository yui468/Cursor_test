# 🎸 Band Hero - バンドヒーロー 🎸

バンドメンバーとしてリズムに合わせて演奏する音楽ゲーム！

## 🎮 ゲームの遊び方

### 基本操作
- **A** - ギター 🎸
- **S** - ベース 🎵  
- **D** - ドラム 🥁
- **F** - ボーカル 🎤

### ゲームプレイ
1. 画面上から落ちてくるノートに合わせてキーを押す
2. タイミングが良いほど高得点！
3. コンボを繋げてスコアを倍増させよう
4. HPが0になるとゲームオーバー

### 評価システム
- **PERFECT** - 完璧なタイミング！（100点）
- **GOOD** - 良いタイミング（50点）
- **OK** - まずまずのタイミング（25点）
- **MISS** - タイミングが悪い（HPダメージ）

## 🎵 特徴

- **リアルタイム音響生成** - Web Audio APIを使用した楽器音
- **美しいビジュアルエフェクト** - Canvas 2Dによる滑らかなアニメーション
- **プロシージャル背景音楽** - 動的に生成される伴奏
- **コンボシステム** - 連続ヒットでスコア倍増
- **レスポンシブデザイン** - 様々な画面サイズに対応

## 🚀 起動方法

### ローカル環境
1. ブラウザで `index.html` を開く
2. または `python3 -m http.server 8080` でローカルサーバーを起動
3. 「ゲームスタート」をクリック
4. 楽しもう！

### Vercelでのデプロイ

#### 方法1: Vercel CLI を使用
```bash
# Vercel CLI をインストール
npm i -g vercel

# プロジェクトディレクトリで実行
cd band-hero
vercel

# 本番デプロイ
vercel --prod
```

#### 方法2: GitHub連携
1. このプロジェクトをGitHubリポジトリにプッシュ
2. [Vercel](https://vercel.com) にサインアップ/ログイン
3. 「New Project」をクリック
4. GitHubリポジトリを選択
5. 自動的にデプロイが開始されます

#### デプロイ後のURL
- プレビュー: `https://band-hero-[random].vercel.app`
- 本番: `https://band-hero.vercel.app` (カスタムドメイン設定時)
