# 🎸 Band Hero - バンドヒーロー 🎸

バンドメンバーとしてリズムに合わせて演奏する音楽ゲーム！

## 🎮 ゲームの遊び方

### 基本操作
- **A** - ギター 🎸
- **S** - ベース 🎵  
- **D** - ドラム 🥁
- **F** - ボーカル 🎤

### ゲームプレイ
1. 画面上から落ちてくるノートに合わせてキーを押す
2. タイミングが良いほど高得点！
3. コンボを繋げてスコアを倍増させよう
4. HPが0になるとゲームオーバー

### 評価システム
- **PERFECT** - 完璧なタイミング！（100点）
- **GOOD** - 良いタイミング（50点）
- **OK** - まずまずのタイミング（25点）
- **MISS** - タイミングが悪い（HPダメージ）

## 🎵 特徴

- **リアルタイム音響生成** - Web Audio APIを使用した楽器音
- **美しいビジュアルエフェクト** - Canvas 2Dによる滑らかなアニメーション
- **プロシージャル背景音楽** - 動的に生成される伴奏
- **コンボシステム** - 連続ヒットでスコア倍増
- **レスポンシブデザイン** - 様々な画面サイズに対応

## 🚀 起動方法

1. ブラウザで `index.html` を開く
2. 「ゲームスタート」をクリック
3. 楽しもう！

## 🔧 技術仕様

- **HTML5 Canvas** - ゲーム描画
- **Web Audio API** - 音響システム
- **JavaScript ES6+** - ゲームロジック
- **CSS3** - スタイリングとアニメーション
